# 数据与许可证说明

## 代码

项目代码使用 MIT License，详见仓库根目录 `LICENSE`。

## 历史活动资料

仓库中的历史活动案例是从项目组过往活动材料整理出的结构化摘要。原始 Word、Excel 等资料可能包含内部信息，未提交到公开仓库，也不包含在 Docker 镜像中。

官网部署后，用户上传的资料由官网按自身存储和权限规则保存到 R2。嘉会通过短期签名链接读取文件，提取的文本仅用于本次历史案例整理请求。异步任务输入和结果在 `JOB_DATA_DIR` 中保留至任务到期，默认 24 小时。

## 第三方依赖

Node.js 依赖及其版本记录在 `package-lock.json`。部署前可运行：

```bash
npm ci
npm audit --omit=dev
```

经费表模板位于 `server/templates/`，由项目组根据既有活动表格整理，随服务发布。

界面使用系统字体，没有打包第三方字体。图标来自 `lucide-react`，其许可证随 npm 包安装。React、Express、Mammoth、JSZip、Zod 等第三方包按各自许可证使用。

模型服务由部署方选择并配置。上线前需确认所选供应商的账号归属、费用、限流、数据保留和使用条款。嘉会只要求兼容 OpenAI Chat Completions 的接口，不在代码中绑定某一家供应商。
